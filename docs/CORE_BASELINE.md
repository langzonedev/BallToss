# Lang Systems Core Baseline

- Adopted 9 November 2026 from [Lang Systems Core Development](https://github.com/langzonedev/LangSystems-Core-Development).
- BallToss is a public, static arcade game. Canvas renders the scene, browser input drives an analytic flight model, and Web Audio synthesises the effects. Score and mute preference stay in browser storage.
- Acceptance covers touch and keyboard input, charge guidance, normal and perfect catches, ceiling impact, missed catch, replay and local high score. Browser verification precedes handoff. The human playtest evaluates timing and sound on a physical phone.
- Direct publication from `main` is authorised for the playtest candidate.
