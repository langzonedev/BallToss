# BallToss

A one-button Lang Systems Arcade game from the point of view of someone lying in bed with a tennis ball.

- Hold the playfield to build power. Release in the highlighted range for a clean throw.
- Tap when the ball drops into the catch ring. Space works for the same actions on a keyboard.
- A sweet-spot throw and a perfectly timed catch earn a perfect combo. Consecutive perfect combos build a streak.
- The ceiling and your face end the run. Hold again for a fresh attempt.

The game is a static HTML, CSS and Canvas project. Serve the repository root with `python3 -m http.server` for local development. GitHub Pages publishes the root of `main`. The high score and mute preference are saved on the current browser.
